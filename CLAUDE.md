# CLAUDE.md

This repo is Studytube's generated mirror of [mattpocock/skills](https://github.com/mattpocock/skills), kept so Devin discovers the skills via `.agents/skills/`. It is not a maintained fork; see [README.md](README.md) for the full picture.

Rules for working here:

- Never edit anything under `.agents/skills/` or `.agents/UPSTREAM_VERSION` by hand: both are regenerated by the `Sync skills from upstream` workflow (`.github/workflows/sync-skills.yml`) and manual changes are overwritten on the next sync. Skill improvements belong upstream.
- Never merge or rebase upstream git history into this repo. Syncing is file-level only, through the workflow.
- The repo intentionally contains nothing else: the workflow, `scripts/sync-agents-skills.sh`, the mirror, the version file, LICENSE, and the docs. Do not reintroduce upstream's package tooling, changesets, or release workflow.
